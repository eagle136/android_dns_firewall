# 黑名单（流水线阶段1，命中 = 拦截候选；被白名单豁免则放行）
# 本文件就是生效配置：保存后 dnsfw 用 inotify 自动重载，不需要重启服务。
# 命中后 A 查询回 127.0.0.1，其它类型回 NXDOMAIN，不向上游发这个查询。
#
# 每行一个条目。# 之后是行内注释，行首 # 是整行注释；大小写不敏感，自动去重，
# 首尾多余的空格和点会被去掉（example.com. 与 example.com 等价）。
# 只有 '*' 是通配符；其余字符只接受字母/数字/-/_/.，格式不正确的行整条跳过并告警。
#
#   test.com        匹配 test.com 本身 + 任意深度的子域（a.b.test.com）
#   *.test.com      与上一行完全等价（会折叠进精确集合，不重复计一条）
#   ad*.com         任意位置通配：以 ad 开头且以 .com 结尾
#   *tracker*       域名中包含 tracker
#
# 单标签条目（如 com、local）会被拒收并告警——它会拦掉整个 TLD。
# test.com 和 *.test.com 效果相同，选一种写法即可。
#
# 示例:
# *.doubleclick.net
# ad.example.com
