# 白名单（流水线阶段2：只对黑名单命中项起豁免作用）
# 本文件就是生效配置：保存后 dnsfw 用 inotify 自动重载，不需要重启服务。
# 语法与黑名单完全相同（大小写不敏感、行内 # 注释、尾点忽略、'*' 通配；格式不正确的行跳过）:
#
#   test.com        豁免 test.com 本身 + 任意深度子域
#   *.test.com      与上一行等价
#   ad*.com / *tracker*   任意位置通配
#
# 白名单不单独放行任何东西：黑名单没命中的查询本来就直接透传。
# 豁免是按域名后缀匹配的，写 ok.api.example.com 只豁免这一个名字，
# 同域下的 other.api.example.com 仍会被 api.example.com 那条黑名单拦掉。
#
# 注意: 白名单这一侧不检查单标签条目（写 com 会豁免掉所有 .com 的黑名单命中），
# 建议一律写全名。
#
# 示例:
# *.api.example.com
